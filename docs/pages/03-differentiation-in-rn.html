Differentiation in $\mathbb{R}^n$ [S+N]¶

For $f : U \subseteq \mathbb{R}^n \to \mathbb{R}^m$, "differentiable at $x_0$" means: there exists a linear map $L : \mathbb{R}^n \to \mathbb{R}^m$ such that

$$\lim_{h \to 0} \frac{\|f(x_0 + h) - f(x_0) - L(h)\|}{\|h\|} = 0.$$

When such an $L$ exists, it's unique and called the (total) derivative $Df(x_0)$. Its matrix in standard coordinates is the Jacobian:

$$Df(x_0) = J = \begin{pmatrix} \partial f_1 / \partial x_1 & \cdots & \partial f_1 / \partial x_n \\ \vdots & & \vdots \\ \partial f_m / \partial x_1 & \cdots & \partial f_m / \partial x_n \end{pmatrix}.$$

This notebook walks the standard hierarchy:

  1. Partial derivatives — the components of $J$.
  2. Total derivative as the best linear approximation.
  3. Critical pitfall: partials can exist without the function being differentiable.
  4. Chain rule in matrix form.
  5. Maxima symbolic Jacobians.

The total derivative as best linear approximation¶

Geometrically, $f(x_0 + h) \approx f(x_0) + J(x_0)\,h + o(\|h\|)$. The plane through $(x_0, f(x_0))$ tangent to the graph of $f$ has slope $J$.

For a scalar $f : \mathbb{R}^2 \to \mathbb{R}$, this is the tangent plane:

$$z = f(x_0, y_0) + f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0).$$

Partials exist ≠ differentiable¶

A subtlety with no 1D analogue: a function can have all partial derivatives at a point and still not be differentiable there.

Take $f(x, y) = xy/(x^2 + y^2)$ for $(x, y) \ne 0$, $f(0, 0) = 0$. Both partials at the origin are 0:

In [63]:
/* f(x, 0) = 0 for all x, so ∂f/∂x at origin = lim (f(h, 0) - f(0,0))/h = 0
   Similarly for ∂f/∂y. But f isn't even continuous at origin (previous notebook),
   let alone differentiable. */
print("∂f/∂x at origin = lim_{h→0} (f(h, 0) - 0)/h = 0   (f vanishes on the x-axis)")$
print("∂f/∂y at origin = 0   (similarly on y-axis)")$
print("But f isn't continuous at origin, so it can't be differentiable.")$

∂f/∂x at origin = lim_{h→0} (f(h, 0) - 0)/h = 0   (f vanishes on the x-axis)
∂f/∂y at origin = 0   (similarly on y-axis)
But f isn't continuous at origin, so it can't be differentiable.

Sufficient condition for differentiability: if all partials exist and are continuous in a neighbourhood of $x_0$, then $f$ is differentiable at $x_0$ (in fact $C^1$). This is the criterion you actually use in practice.

Chain rule in matrix form¶

For composable functions $f : \mathbb{R}^n \to \mathbb{R}^m$ and $g : \mathbb{R}^m \to \mathbb{R}^k$, both differentiable, the composition $g \circ f$ is differentiable with

$$D(g \circ f)(x) = Dg(f(x)) \cdot Df(x).$$

The 1D chain rule $(g \circ f)' = g'(f) \cdot f'$ is the special case $n = m = k = 1$. The matrix form generalises naturally.

Maxima can verify this on a concrete example.

In [64]:
/* f: ℝ² → ℝ²,  g: ℝ² → ℝ */
f_inner : [x^2 + y, x*y]$
g_outer : (u + v)^2$
J_f : genmatrix(lambda([i, j], diff(f_inner[i], state_vars[j])), 2, 2)$
J_g : matrix([diff(g_outer, u), diff(g_outer, v)])$
print("J_f =")$ J_f;
print("J_g (in u, v) =")$ J_g;

/* Compose:  h(x, y) = g(f(x, y)) = (x²+y + xy)²  */
h_composed : subst([u = f_inner[1], v = f_inner[2]], g_outer)$
J_h_direct : matrix([diff(h_composed, x), diff(h_composed, y)])$
print("∂(g∘f)/∂(x,y) directly =")$
expand(J_h_direct);

/* Chain rule: J_h = J_g(at f) · J_f */
J_g_at_f : subst([u = f_inner[1], v = f_inner[2]], J_g)$
J_h_via_chain : J_g_at_f . J_f$
print("∂(g∘f)/∂(x,y) via chain rule =")$
expand(J_h_via_chain);

print("Matches:", is(equal(expand(J_h_direct), expand(J_h_via_chain))))$

Why the matrix view matters¶

The chain rule expressed as matrix multiplication generalises seamlessly to:

  • Backpropagation in neural networks (the chain rule applied through stacked layers).
  • Coordinate changes in physics — the metric tensor transforms by Jacobian congruence, $g' = J^{\mathsf{T}} g\, J$. (Congruence, not conjugation: $g$ is a bilinear form, not an operator.)
  • Implicit function theorem — if $\partial F/\partial y$ is invertible, you can solve $F(x, y) = 0$ locally for $y(x)$ (next notebook).

The total-derivative perspective also reveals what "differentiable" really means: not "you can take any partial", but "you have a coherent linear approximation that works in every direction simultaneously." The 1D case hides this because there's only one direction.
